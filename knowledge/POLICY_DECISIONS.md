# تصميم سياسات البنك الافتراضي — الإصدار 1.0

هذه قرارات تصميم لمحاكاة مشروع التخرج، وليست شروط بنك حقيقي أو استشارة مالية أو
متطلبات قانونية. اختيرت بعد تفويض صاحب المشروع بتصميم السياسات. لا تعني موافقة
جهة مصرفية أو تشغيل الخدمات المالية. تاريخ الإصدار 2026-11-02.

المصدر الذي يقرأه RAG هو ملفات `policies/*.md` فقط؛ هذا الملف سجل قرارات للمراجعة.

## حدود التنفيذ

- RAG يشرح القواعد ولا ينفذ إجراءات مالية أو يصل إلى أرصدة فعلية.
- سؤال السياسات المحلي بلا تسجيل دخول؛ بيانات العميل والعمليات تحتاج تحققًا وصلاحيات.
- OCR لا يثبت ملكية البطاقة ولا يدخل نصه أو صوره في فهرس السياسات.
- الحدود والأسعار افتراضية قابلة للتغيير. عند تغييرها حدّث الملف، رقم الإصدار، هذا
  السجل، وحالات القبول ثم أعد الاختبارات. لا تعدّل توقعات الاختبار لإخفاء إخفاق النموذج.
- API يحتاج إعادة استيراد السياسات بعد تعديلها؛ التشغيل المحلي يقرأ الملفات عند البدء.
- العطل الرسمية ليست محددة بتقويم تلقائي؛ لا تقدم تاريخ تنفيذ مؤكد من RAG.
- لا تعتمد مبلغ قسط أو إجمالي فائدة محسوبًا بواسطة النموذج؛ الآلة الحاسبة المالية مرحلة أخرى.
