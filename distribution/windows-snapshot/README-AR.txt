BankWise — نسخة Windows كاملة بالموديلات والبيانات الحالية

قبل التشغيل (مرة واحدة)
1. يلزم جهاز Windows مدعوم بمعالج Intel/AMD 64-bit، وليس Windows ARM.
2. ثبّت Docker Desktop من الموقع الرسمي:
   https://docs.docker.com/desktop/setup/install/windows-install/
   اختر WSL 2 وLinux containers. أكمل إعداد WSL/Virtualization وأعد التشغيل إذا طلب المثبّت.
3. افتح Docker Desktop وانتظر اكتمال التشغيل.
4. يفضل RAM 24 GB؛ جهاز 16 GB قد يحتاج غلق البرامج الأخرى وإتاحة ذاكرة كافية لـDocker.
   اترك نحو 25 GB مساحة للتنزيل وفك الضغط وصور Docker والبيانات.
   لا يلزم NVIDIA GPU: هذه النسخة تعمل على CPU، والسرعة تختلف حسب الجهاز.

التشغيل
1. فك ZIP بالكامل في مسار قصير، مثل C:\BankWise. لا تشغّل الملفات من داخل ZIP.
2. افتح المجلد الذي يحتوي على Start.bat وcompose.yaml.
3. شغّل Start.bat وانتظر. أول مرة يتم استيراد صور Docker واستعادة قاعدة البيانات وتحميل الموديلات؛ قد يستغرق عدة دقائق.
4. المتصفح يفتح http://127.0.0.1:8501 تلقائيًا بعد جاهزية التطبيق.
5. استخدم نفس أسماء المستخدمين وكلمات المرور الموجودة في نسخة صاحب المشروع.
6. للإيقاف شغّل Stop.bat. في المرات التالية افتح Docker Desktop ثم Start.bat.

المحتويات
- Qwen3.5-4B Q4_K_M وllama.cpp: موجودان بالكامل؛ لا تحتاج تنزيل الموديل.
- EasyOCR العربية والإنجليزية وكاشف النصوص: موجودة؛ لا تحتاج تنزيل موديلات OCR.
- multilingual-e5-small للبحث الدلالي: موجود بالكامل.
- صور Docker للواجهة والـAPI وPostgreSQL: موجودة داخل images.tar.gz.
- قاعدة البيانات والحسابات والأرصدة والمعاملات وطلبات الهوية ومفاتيحها من نسخة صاحب المشروع.
- مجلد source يحتوي على نسخة المشروع الحالي بما فيها البيانات والملفات المحلية الموجودة وقت تجهيز الحزمة.
- لا تحتاج تثبيت Python أو pip أو مكتبات المشروع على Windows.
- الإنترنت مطلوب لتثبيت Docker/WSL أول مرة، وليس لتنزيل موديلات التطبيق أو تشغيله محليًا بعد التجهيز.
- EasyOCR هو الافتراضي؛ تجارب YOLO/Paddle/CRNN ليست مفعلة بدلًا منه.

البيانات
كل جهاز يستعيد نسخة مستقلة أول مرة؛ التغييرات لا تتزامن مع جهاز صاحب المشروع.
استعادة البيانات لا تتكرر فوق بياناتك عند إعادة التشغيل.
احتفظ بملفي .env وruntime.env؛ يحتويان على إعدادات ومفاتيح لازمة لفتح بيانات الهوية.
لا تستخدم docker compose down -v إلا إذا كنت تقصد مسح بيانات هذه النسخة على جهازك.

حل المشاكل
- Docker غير موجود أو غير شغّال: ثبّته وافتحه أولًا، واختر Linux containers.
- المنفذ 8501 مستخدم: غيّر BANKWISE_UI_PORT في .env إلى 8502 ثم شغّل Start.bat.
- الذاكرة غير كافية: أغلق البرامج الأخرى وراجع موارد Docker/WSL.
- فشل البدء: افتح PowerShell في مجلد الحزمة وشغّل docker compose logs --tail 50.
- للتحقق من سلامة الملفات: شغّل Verify.bat (قراءة ملفات الموديلات الكبيرة قد تستغرق وقتًا).

حدود الاختبار
تم اختبار الحاويات والاستعادة وقراءة OCR واستجابة Qwen والواجهة على Linux x86_64.
لم يتوفر جهاز Windows لاختبار PowerShell وDocker Desktop/WSL فعليًا؛ لا يمكن ضمان أداء كل جهاز.
