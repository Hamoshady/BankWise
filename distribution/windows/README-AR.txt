BankWise — نسخة مشاركة لويندوز (Intel / AMD 64-bit)

المطلوب قبل التشغيل
1) ثبّت Docker Desktop من الموقع الرسمي، وفعّل WSL 2 وLinux containers:
   https://docs.docker.com/desktop/setup/install/windows-install/
2) يُنصح بجهاز RAM 16 GB أو أكثر، وإتاحة نحو 10–12 GB لـDocker، ومساحة فارغة 25 GB.
   الأداء يعتمد على المعالج. هذه النسخة CPU؛ لا تحتاج كارت شاشة NVIDIA.
3) ليست نسخة Windows ARM. يلزم تثبيت Docker/WSL أولًا بالإنترنت؛ بعد ذلك موديلات التطبيق موجودة داخل الحزمة.

التشغيل
- فك الضغط بالكامل في مسار قصير مثل C:\BankWise؛ لا تشغّل من داخل ZIP.
- افتح Docker Desktop وانتظر حتى يعمل.
- افتح Start.bat. أول مرة سيحمّل صور Docker من images.tar ويهيئ قاعدة بيانات جديدة.
- انتظر تجهيز الموديل؛ قد يستغرق عدة دقائق. تفتح الواجهة على http://127.0.0.1:8501
- لا تحتاج تثبيت Python على Windows.
- للتحقق من سلامة الملفات قبل التشغيل: powershell -NoProfile -ExecutionPolicy Bypass -File Verify.ps1
- للإيقاف استخدم Stop.bat. التشغيل التالي بنفس Start.bat، وتظل حساباتك محفوظة في Docker volumes.

الحسابات والهوية
- أنشئ حسابك من الواجهة؛ يبدأ برصيد صفر ويحتاج مراجعة الهوية.
- افتح نافذة خاصة لتسجيل دخول المسؤول: identity_officer
- كلمة مرور المسؤول تتولّد على جهازك، وتجدها أمام BANKWISE_INITIAL_ADMIN_PASSWORD في ملف .env الذي يُنشأ عند أول تشغيل.
- لا تغيّر أو تمسح .env بعد إنشاء الحسابات، خاصة BANKWISE_REVIEW_KEY؛ المفاتيح لازمة لقراءة طلبات الهوية المشفّرة.
- أرسل صور البطاقة من حساب العميل، ثم راجعها ووافق من شاشة المسؤول. التفعيل لا يضيف رصيدًا ولا يمثل حسابًا بنكيًا حقيقيًا.
- لا يوجد في الحزمة حساب صاحب المشروع أو كلمات مروره أو قاعدة بياناته أو صور بطاقته.

المحتويات
- Qwen3.5-4B Q4_K_M + llama.cpp b12359.
- multilingual-e5-small للبحث، وموديلات EasyOCR العربية والإنجليزية وكاشف النصوص.
- صور Docker للخدمة والواجهة وPostgreSQL؛ مصدر الكود في source.
- ملخصات سياسات CIB وروابطها الرسمية. ليست اتصالًا بالبنك ولا بديلًا عن عقوده.
- موديلات التجارب القديمة Qwen2.5 وBGE غير مضمنة؛ ليست مستخدمة في هذا الإعداد.

بيانات Berka التاريخية (اختيارية)
لم تُضمّن نسخة بيانات العملاء والمعاملات التاريخية: المصدر لا يوضح ترخيص إعادة توزيع صريحًا.
لذلك صفحة البيانات التاريخية لن تعرض عينة قبل تنزيلها ومنح حسابك وصولًا لها.
اقرأ المصدر https://relational.fel.cvut.cz/dataset/Financial
ثم شغّل Fetch-Berka.ps1 من PowerShell إذا رغبت في تنزيلها مباشرة للبحث المحلي.
هذا يحتاج الإنترنت واتصالًا بقاعدة المصدر، وقد يفشل إذا توقف المصدر أو حُجب المنفذ 3306.
البرنامج يسأل عن اسم حساب عميل موجود، وينزّل البيانات ويمنحه عينة البحث client_id=1.
لا تستخدم حساب المسؤول للمعاملات أو البحث.

حل المشاكل
- المنفذ 8501 مشغول: عدّل BANKWISE_UI_PORT في .env إلى 8502، وافتح http://127.0.0.1:8502 يدويًا.
- Docker غير جاهز: افتح Docker Desktop وتأكد من Linux containers وWSL 2.
- الخدمة بطيئة/تتوقف: راجع RAM المتاح، ثم docker compose logs --tail 50 api
- لعرض الحالة: docker compose ps
- لا تستخدم docker compose down -v إلا إذا كنت تقصد حذف قاعدة بيانات نسختك.
- لا تشارك نسخة المجلد بعد تشغيله بدون إزالة .env وأي بيانات نزّلتها أو أضفتها.

التحقق
تم اختبار الحاويات على Linux x86_64 بقاعدة بيانات جديدة ومنفصلة عن نسخة صاحب المشروع.
لم يتوفر جهاز Windows هنا لاختبار PowerShell أو WSL فعليًا؛ هذه نقطة تحقق باقية عند المستلم.
